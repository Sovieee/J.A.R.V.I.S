Steps to run J.A.R.V.I.S while in development mode:

Make sure to open two VScode powershell terminals (ctrl + shift + ~)

Steps:
1) To get the backend running, use the command "python api.py"
2) To get the frontend running, use the command "npx electron ." or "npm start"

Make sure you run both commands in separate terminals.

Notes:

~ : Wake word is "Jarvis", so make sure to include this word while giving the first command to activate the system.
~ : This system constantly keeps on accessing microphone to listen to commands, to stop or kill the system press "ctrl + c" in the terminal window.


System Access:

This system will access your:
1) Microphone
2) Location
3) Camera
4) File Manager

in order to enhance user experience and carry out variety of tasks.

Checkout the list of activities that can be performed by using J.A.R.V.I.S as an Personal AI Assistant.
